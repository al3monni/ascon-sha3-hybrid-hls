Piattaforma: x86_64-wsl
  - CPU               : AMD Ryzen 5 5600G with Radeon Graphics (12 core), misura fissata sul core 11
  - Sistema           : Ubuntu 26.04 LTS, kernel 6.6.87.1-microsoft-standard-WSL2
  - Governor / f max  : n/d / n/d kHz
  - Compilatore       : gcc (Ubuntu 15.2.0-16ubuntu1) 15.2.0
  - Flag              : -O2 -march=native -Wno-unknown-pragmas -Wno-unused-label -Wno-unused-variable
  - Data              : 2026-10-09 14:12

Cosa viene misurato (regione cronometrata):
  UNA chiamata a  hash(msg, len, md, mdlen[, mode])  =  hash_init + hash_update
  + hash_final, compilata dai sorgenti Vitis (*-Test/hash.c). Input gia' in
  memoria e caldo in cache (warmup). Esclusi: generazione input, KAT, I/O.

Configurazione:
  - Iterazioni        : 100000 (fase A) + 100000 (fase B) per caso, 1000 warmup
  - Fase A            : per chiamata, timestamp prima/dopo -> distribuzione
  - Fase B            : batch di chiamate consecutive, contatori letti solo
                        prima/dopo il batch -> medie senza overhead del timer
  - Tempo             : clock_gettime(CLOCK_MONOTONIC)
  - Tick              : rdtsc (TSC: frequenza costante di riferimento, non i cicli reali del core), 3892.6 MHz
  - Overhead timer    : 40.0 ns / 39.0 tick per misura (mediana, NON sottratto)
  - PMU               : disponibile (perf_event, solo user-space)
  - Outlier (fase A)  : rimossi con regola IQR (recinto superiore Q3 + 1.5*IQR)
  - Input sintetici   : 16, 64, 256, 1024, 4096 byte (deterministici)
  - Correttezza       : verificata sui vettori KAT prima delle misure

----------------------------------------------------------------------------
LEGENDA
----------------------------------------------------------------------------
  ns          nanosecondi
  tick        unita' del contatore a basso costo (vedi 'Tick' sopra)
  mean/median/sd/min/max  statistiche sui campioni tenuti (fase A)
  out%        percentuale di campioni scartati come outlier (regola IQR)
  ns/hash     tempo medio per hash nella fase B (senza overhead del timer)
  cicli/hash  cicli REALI del core per hash (PMU, solo codice utente)
  istr/hash   istruzioni eseguite per hash (PMU)
  IPC         istruzioni per ciclo = istr/hash / cicli/hash
  cpb         cicli per byte = cicli/hash / dimensione input
              (metrica standard dei benchmark crittografici, es. eBACS)
  byte/s      dimensione / tempo medio (fase A);  hash/s = 1 / tempo medio
  d ...       variazione %: (hybrid - singola)/singola; negativo = hybrid migliore
